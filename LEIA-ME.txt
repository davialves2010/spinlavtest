SpinLav - Aba Frete + Frete grátis + Pagamento online (Mercado Pago)

PARTE 1 - Banco (Supabase > SQL Editor)
  Rode supabase/frete-admin-pagamento.sql  (precisa já ter rodado o pagamento-frete.sql antes)

PARTE 2 - Site (GitHub)
  Substitua assets/spa.js pelo deste zip e faça o commit.
  Já dá para usar: aba "Frete" no painel, frete grátis acima de um valor, botão "Marcar pago" para o admin.

PARTE 3 - Pagamento online (opcional, só quando quiser ativar)
  1. Crie conta no Mercado Pago > "Seu negócio" > Configurações > Credenciais (ou mercadopago.com.br/developers),
     crie uma aplicação (Checkout Pro) e copie o Access Token (comece com o de TESTE).
  2. Supabase > Edge Functions > Secrets, crie:
       MP_ACCESS_TOKEN = (o Access Token)
       SITE_URL        = https://spinlavtest.vercel.app   (sem barra no final)
       MP_SANDBOX      = 1     (SOMENTE enquanto estiver testando; apague ao usar o token de produção)
  3. Supabase > Edge Functions > Deploy a new function > Via Editor:
       - nome: criar-pagamento   -> cole supabase/functions/criar-pagamento/index.ts
       - nome: webhook-pagamento -> cole supabase/functions/webhook-pagamento/index.ts
         e DESLIGUE "Verify JWT" nesta segunda função.
  4. Teste: faça um pedido, agende, vá em "Meus pedidos" > "Pagar agora".
  5. Para valer de verdade: troque MP_ACCESS_TOKEN pelo token de PRODUÇÃO e apague MP_SANDBOX.
